## 📜 Overview

**AETHER** is not just a world clock; it is a temporal visualization engine designed to track time across 50+ global sectors with atomic precision. You can experience the live system directly at **[aether.pulseflow.workers.dev](https://aether.pulseflow.workers.dev/)**.

Built entirely with **Vanilla JavaScript**, it rejects the bloat of modern frameworks in favor of raw speed, optimized DOM manipulation, and a stunning "Glassmorphism 2.0" aesthetic.

---

## ✨ Key Features

* **💎 Cinematic UI:** A deep, immersive interface featuring advanced glassmorphism, ambient lighting, and smooth motion design.
* **⚡ Zero Dependencies:** No React, No Vue, No jQuery. Just 100% pure, native browser technologies.
* **🌐 Atomic Precision:** Utilizes the `Intl.DateTimeFormat` API for accurate, timezone-aware time calculation (handling DST and offsets automatically).
* **🔍 Instant Search:** Real-time filtering algorithm that scans cities, countries, and timezones instantly.
* **📱 Fully Responsive:** Adaptive grid layout that flows perfectly from 4K monitors down to mobile devices.
* **🎨 Dark Mode Native:** Designed from the ground up for low-light environments.

## 🚀 Quick Start

You don't need `npm`, `yarn`, or a build server. This is web development in its purest form.

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/K-z89/AETHER.git
    ```
2.  **Navigate to the folder:**
    ```bash
    cd AETHER
    ```
3.  **Launch:**
    Simply open `index.html` in any modern browser (Chrome, Firefox, Edge, Safari).
